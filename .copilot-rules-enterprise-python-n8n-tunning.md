## 💻 Convenções de Linguagem — `python`

| Aspecto | Convenção |
|---------|-----------|
| Estilo | PEP 8 — formatado com `ruff format` ou `black` |
| Nomenclatura | `snake_case` para funções/variáveis, `PascalCase` para classes |
| Type hints | Obrigatório em funções públicas (`from __future__ import annotations`) |
| Imports | `isort` ou `ruff --select I` — agrupamento stdlib/third-party/interno |
| Linter | `ruff check` ou `flake8` |
| Testes | `pytest` — cobertura mínima 80% — rodar com `uv run pytest` |
| Gerenciador | **`uv`** (➕ preferêncial) — `uv venv`, `uv add`, `uv run`, `uv sync` |
| Virtual env | `.venv/` na raiz (gitignored) — criado com `uv venv` |
| Dependências | `pyproject.toml` (PEP 621) — lock em `uv.lock` (commitar) |
| Scripts | Executar via `uv run <script>` — não ativar `.venv` manualmente |

```markdown
## Resumo da Interação

> Uma frase descrevendo o objetivo principal da conversa.

## Decisões Tomadas

- **[Decisão 1]**: descrição + justificativa
- **[Decisão 2]**: descrição + justificativa

## Ações Realizadas

- [ ] Ação 1 — arquivo/componente afetado
- [x] Ação 2 — arquivo/componente afetado (concluída)

## Artefatos Gerados/Modificados

| Arquivo | Operação | Descrição |
|---------|----------|-----------|
| `caminho/do/arquivo.ext` | criado/editado | breve descrição |

## Pendências

- [ ] Item pendente com contexto suficiente para retomada

## Referências

- [arquivo relacionado](caminho/relativo)
```

#### Critérios para criação obrigatória

- Qualquer mudança em `objetivo.yaml`, `constitution.md`, `plan-template.md`
- Implementação ou edição de código Python/Ansible
- Debate entre agentes com decisão tomada
- Resultado de etapa do ciclo Speckit (specify → clarify → plan → checklist → tasks → analyze → implement)
- Correção de bug ou erro identificado em execução

#### Critérios para omissão (não criar)

- Consultas somente leitura sem decisão
- Perguntas respondidas sem alteração de artefatos
- Retomada de contexto sem novo trabalho produzido
