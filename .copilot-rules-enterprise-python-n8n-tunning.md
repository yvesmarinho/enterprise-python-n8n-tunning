### 3. Mover/copiar/excluir arquivos — SEMPRE Python stdlib

**1–2 arquivos:** `run_in_terminal mv` é aceitável.
**3+ arquivos:** OBRIGATÓRIO Python + JSON (nunca `mv` repetido ou loop shell):

```python
import shutil, logging
from pathlib import Path

log = logging.getLogger(__name__)
root = Path("/home/yves_marinho/Documentos/DevOps/Vya-Jobs/enterprise-python-n8n-tunning")
ops = [
    {"name": "arquivo.md", "from": "origem/", "to": "destino/"},
]
for op in ops:
    src = root / op["from"] / op["name"]
    dst = root / op["to"]  / op["name"]
    dst.parent.mkdir(parents=True, exist_ok=True)
    if src.exists():
        shutil.move(str(src), str(dst))
        log.info("✅ %s → %s", op["from"], op["to"])
```

❌ **PROIBIDO**: `mv`, `cp`, `rm`, `mkdir` em série via terminal para lotes

**Todos os servidores VPS utilizam SSH SPA (fwknop) com porta custom.**

| Servidor | IP | Porta SSH | Função |
|----------|----|-----------|--------|
| wf001.vya.digital | 31.220.103.208 | 5010 | N8N produção |
| wf008.vya.digital | 31.220.103.208 | 5010 | Journey System |
| wfdb01.vya.digital | 86.48.31.149 | 5010 | Observability + N8N teste |
| wfdb02.vya.digital | 82.197.64.145 | 5010 | PostgreSQL/MySQL produção |

**Configuração em**: `.secrets/ssh.json`

### Acesso Manual

```bash
# Knock SPA antes de qualquer conexão SSH
make ssh-spa-knock                              # todos os servidores
make ssh-spa-knock-one HOST=wfdb01             # servidor específico

# Script dedicado wfdb01 (knock automático):
~/.local/bin/ssh-wfdb01 'docker ps'            # comando remoto
~/.local/bin/ssh-wfdb01 --test                 # knock + verifica porta
~/.local/bin/ssh-wfdb01                        # sessão interativa
```

**Janela de acesso**: 30 segundos após knock (fw_timeout)
**Porta knock**: UDP 62201 | **Porta SSH**: TCP 5010

### Regras Críticas fwknop

| Sintaxe | Válida? |
|---------|:-------:|
| `$IP` / `$SRC` | ✅ |
| `%IP%` / `%SRC%` | ❌ (passa literalmente — UFW rejeita) |

**UFW — Primeira regra ganha**: usar `ufw insert 1 allow from $IP to any port 5010` para inserir ANTES do DENY.

## 🏗️ Ansible — Padrão de Playbook com SPA

**Todo playbook que acessa servidores VPS deve ter Play 1 como SPA knock:**

```yaml
# Play 1: localhost — SPA knock
- name: SPA Knock
  hosts: localhost
  connection: local
  tasks:
    - name: Enviar knock SPA
      command: fwknop --rc-file ~/.fwknoprc -n {{ inventory_hostname }}
    - name: Aguardar janela SPA
      pause:
        seconds: 3
    - name: Verificar porta SSH disponível
      wait_for:
        host: "{{ ansible_host }}"
        port: 5010
        timeout: 30

# Play 2: remoto — deploy/configuração
- name: Deploy / Configuração
  hosts: <host>
  become: false    # usar become apenas onde necessário
  tasks:
    # Docker SEMPRE como docker_user
    - name: Reiniciar serviço N8N
      command: docker compose up -d n8n
      args:
        chdir: /opt/docker_user/n8n
      become: true
      become_user: docker_user
```

**Paths corretos nos servidores VPS:**

| Servidor | Path Docker N8N | Path Docker padrão |
|----------|-----------------|--------------------|
| wf001 | `/opt/docker_user/n8n` | `/opt/docker_user` |
| wfdb01 | `/opt/docker_user/n8n` (teste) | `/opt/docker_user` |
