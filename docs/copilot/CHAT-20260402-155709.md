## Decisões Tomadas

1. **VictoriaMetrics não exposta externamente**: porta 8428 não publicada ao host em
   wfdb01 por design de segurança. `collect_gate_evidence.py` adaptado para suportar
   fallback via endpoint direto N8N (`--n8n-url`).

2. **Evidência T017 via endpoint direto**: Gate F16 validado usando
   `check_n8n_metrics.py --metrics-url https://testn8n.vya.digital` em vez de
   VictoriaMetrics (que não tem dados de wfdb01 — Prometheus não raspa wfdb01/N8N).

3. **`ansible_user: archaris`**: SSH para VPS usa usuário `archaris` (via SSH agent),
   não `docker_user`. Operações docker usam `become_user: root` (root pode escrever no
   diretório docker_user com owner/mode corretos).

4. **`become_user: root` para template**: Usar `become_user: docker_user` falha por ACL
   de arquivo temporário (`chmod A+user:docker_user:rx:allow` inválido no Linux). Root
   escreve o arquivo e define `owner: docker_user; group: docker_user; mode: 0644`.

5. **Template multi-service**: `docker-compose.override.j2` refatorado para loop Jinja2
   sobre `n8n_services` list (configurável por environment). wfdb01 usa
   `[n8n_editor, n8n_worker, n8n_webhook, n8n_mcp]`.
