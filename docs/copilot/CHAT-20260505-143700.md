### 2. Correção Bug #3 — Verificação em Check Mode
**Problema**: Tasks `ansible.builtin.uri` são puladas em `--check` mode, causando variáveis `healthz_check` e `metrics_check` não registradas.

**Solução implementada**:
```yaml
# Antes (falhava em --check):
- name: AFTER | Verificar healthz N8N
  ansible.builtin.uri:
    url: "https://n8n.vya.digital/healthz"
    ...
  register: healthz_check

# Depois (executa sempre):
- name: AFTER | Verificar healthz N8N
  ansible.builtin.uri:
    url: "https://n8n.vya.digital/healthz"
    ...
  register: healthz_check
  check_mode: false  # ← ADICIONADO

- name: AFTER | Exibir resultado
  ansible.builtin.debug:
    msg:
      - "healthz: {{ healthz_check.status | default('N/A') }}"  # ← SAFE DEFAULT
```

**Arquivo**: [ansible/playbooks/t034a-promote-f16-f17-wf001.yml](../../ansible/playbooks/t034a-promote-f16-f17-wf001.yml) (linhas 147-168)
